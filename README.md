## ✨ Features

| Category | Tools |
|----------|-------|
| 📦 **Compress** | 4 compression levels (Screen, Ebook, Printer, Prepress) |
| 🔄 **Convert** | Convert Word/Excel/PPT to PDF (requires LibreOffice) |
| 🖼️ **Images** | Extract JPEG/PNG from PDF with DPI control |
| 🔗 **Merge** | Combine multiple PDFs into one |
| ✂️ **Extract** | Extract specific page ranges |
| 🔒 **Security** | Add password protection |
| 📝 **OCR** | Extract text content from PDFs |
| ℹ️ **Metadata** | View PDF file information |
| 📊 **Batch** | Process entire folders |

## 📦 Installation

### Prerequisites

1. **Python 3.7+** - [Download Python](https://www.python.org/downloads/)
2. **Ghostscript** - Required for PDF operations
   - [Download Ghostscript](https://ghostscript.com/releases/gsdnld.html)
   - Install to default location: `C:\Program Files\gs\`
3. **LibreOffice** (Optional - for document conversion)
   - [Download LibreOffice](https://www.libreoffice.org/download/)

### Quick Start

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/space-pdf-studio.git
cd space-pdf-studio

# Install dependencies
pip install -r requirements.txt

# Run the application
python pdf_studio.py
